# Account skills (source copies)

These four skills live on your claude.ai account, which makes them available in chat, in
claude.ai Projects, in local Claude Code (synced to ~/.claude/skills/synced/) and in cloud
sessions. This folder is only the source to edit; to change a skill, edit it here and update it on
claude.ai (or ask Claude to propose the change).

test-first and root-cause-debugging are adapted from obra/superpowers (MIT, see
LICENSE-superpowers.txt).
